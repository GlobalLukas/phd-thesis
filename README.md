# phd-thesis

Based on https://github.com/uhh-lt/thesis-template-uhh-lt-latex. Make a full build using *latexmk* by simply typing 

`$> latexmk` 

or more explicit:

`$> latexmk -pdf -bibtex` 

(see latexmkrc for reference). Run 

`$> latexmk -c` 
 
 or more explicit:

 `$> latexmk -pdf -bibtex -c`

to clean temporary output files. Use a capital `-C` to clean generated pdf files too.
